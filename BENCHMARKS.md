# BENCHMARKS — The Graded Tests

Tiers are earned here, not assumed. Run a benchmark exactly as written, log every attempt
in SESSION-LOG.md, and record passes in CHARTER.md's tier table with log references.
Fixed tests, honestly reported — gaming a benchmark to earn a tier is the one unforgivable
sin in this system, because JJ is trusting the tier, not watching the screen.

## B0 — Chores reliability (grants/keeps Tier 0→1 eligibility)

- Full chore circuit (PLAYBOOK order) with before/after balances recorded.
- **Pass:** all visible collectors + Loot Cart collected, balances verified increased,
  zero wrong-screen errors, in 3 consecutive sessions.

B0 session → Tier 1 → B1 drills → B2 attempts.

## B1 — Control drills (attacking prerequisite; Tier 1 — unlocks after B0)

On any Practice base, demonstrate each, confirmed on the result/post-action state.
Practice stages use PRESET armies — that's fine for B1, which tests controls, not
composition:
- [ ] Deploy each hero individually, on the intended tile area
- [ ] Manually trigger a hero ability and CONFIRM it fired (this is the known weak point)
- [ ] Deploy 10+ of one troop with zero missed selections
- [ ] Place 2 spells on intended targets
- [ ] Deploy a siege machine and confirm it registered

## B3 — Farming standard (keeps Tier 2; reviewed every 10 farming attacks)

- Rolling 10-attack window: total loot gained vs army cost must be positive, and no more
  than 2 attacks under 30% (dead attacks) in the window.
- Failing B3 twice running drops the agent back to practice (Tier 1) until B2 is re-passed.
