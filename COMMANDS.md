# COMMANDS — JJ's one-line orders (JJ design session, 2026-11-18)

JJ says one line; whichever seat is open (Sol or Sonnet, interchangeable)
runs the routine, logs it, updates TRACKER.md, and reports to Fin in the
Muse chat. Trigger phrases are a family — any natural phrasing of the
command counts. Every run ends with: SESSION-LOG entry + TRACKER update +
one lesson line in the PLAYBOOK when something was learned (routes,
mis-taps, prices). That loop is how the seats get better at these.

## "chores" (also: "morning chores", "daily chores", "do chores")
The full collection circuit, no battles:
1. Home Village: tap all collectors; Loot Cart if present; Treasury read
   (collect only to fund a same-session start, slot verified first).
2. Builder Base: collectors + Gem Mine; clear NORMAL obstacles only.
   (Main-base obstacles are NOT cleared by this routine — JJ, 2026-11-18.
   Event obstacles are never cleared anywhere, ever — hard rail.)
3. Claims sweep, everything free, all logged: Daily Tasks, Gold Pass free
   track, Season Challenges rewards, event free tracks, achievement
   rewards (claiming earned gems is fine; SPENDING gems never is).
4. Update TRACKER.md: pass tiers/points, unclaimed rewards, challenges
   remaining, Star Bonus status, what was collected (totals).
Choice nodes: seat decides, logs the pick. Paid tracks / gem offers: never.

## "attacks" / "attacks xN" (also: "perform attacks", "go attack")
Run the current attack package (ATTACK-PLAN: S1-B Narrow, Army 1 preset)
for N real multiplayer battles (default: work the current block, max 5).
Standing package rules apply: zoom-out before deploying, open-grass edge,
Freeze on the engaging threat, stop rules (two straight 0-stars or >2
deployment misses = pause + report). DE-rich targets preferred inside the
rubric while Phoenix is unfunded. Every battle reported to Fin as it lands.
Until a seat passes B2 these fly under trial conditions and are logged
per operator; they are also how DE and loot get farmed.

## "upgrades" (also: "do upgrades", "start upgrades")
Trigger-check every slot — builders, Lab, Pet House. For each free slot,
start the highest PRIORITIES queue item that is affordable, menu-verified
at current prices, priority-check-before-spend stated in the log first
(Phoenix before any competing DE spend). Nothing off-queue without a Fin
ruling. If a slot stays idle, log why (funds / queue) — never idle silently.

## "status" (also: "check status", "where are we")
Read-only. Refresh STATE (balances with zoomed gem read, all timers,
Lab, Pet House), summarize TRACKER, report to Fin/JJ. Nothing tapped that
spends, starts, or claims.

## "full run" (also: "run it", "do everything")
chores -> upgrades -> attacks, in that order, one session. This is the
default when JJ just says to run the account.

## Hard rails (every command, no exceptions)
No gems spent, no money, no Ranked sign-up, no event obstacles, no clan
social actions, no boost items inside attack runs, no CC payload requests.
Unexpected dialog = stop, screenshot in log, report. Goblin Builder dialog
= close, never pay.
